# 🏦 Horizon Bank Application

Horizon Bank is a simple banking application developed using PHP and MySQL. It allows users to manage customer records and perform basic banking operations through a menu-driven interface.

## 🚀 Features

- ➕ Add new customers
- 📋 View all customers
- 🔍 Search for a customer by ID
- 💰 Credit / Deposit money
- 💸 Debit / Withdraw money
- ✏️ Update customer details
- 🗑️ Delete customer records
- 🗄️ Store and manage customer data using MySQL

## 🛠️ Technologies Used

- **PHP** – Backend programming
- **MySQL** – Database management
- **MySQLi** – Database connectivity
- **OOP** – Object-Oriented Programming

## 📂 Project Structure

```text
HorizonBank/
├── db.php
├── Customer.php
├── Transaction.php
└── index.php
```

## ⚙️ Installation and Setup

1. Install PHP and MySQL on your system.
2. Create a MySQL database and a `Customers` table.
3. Configure your database connection in `db.php`.
4. Place the project files in your project folder.
5. Open a terminal in the project directory.
6. Run the application using:

```bash
php index.php
```

**Note:** This application uses PHP's `readline()` function and is intended to run in the command-line interface (CLI).
